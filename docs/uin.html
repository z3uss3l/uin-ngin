UIN — Universal Image Notation
Standard v0.1 (Frozen)

Status: FROZEN (Core)
Ziel: Deterministische, KI-freie Bild- & Szenenbeschreibung mit optionalen Erweiterungen.

A — Structural Profile (Core)

  • JSON-basiert, schema-validierbar
  • Deterministisch, reproduzierbar
  • Keine implizite Semantik
  • Kein KI-Zwang

Core-Domänen:

  • geometric_2d
  • geometric_3d
  • forensic
  • semantic (beschreibend, nicht generativ)

C — UIN Inspector (Reference Tool)

Pflicht-Checkliste (MVP)

  • JSON Schema Validation (hart, blocking)
  • 2D SVG-Rendering (deterministisch)
  • Objekt- & Relationsliste
  • Koordinaten- & Anchor-Visualisierung
  • Fehleranzeige schema-nah

Explizit ausgeschlossen

  • KI-Interpretation
  • Prompt-Optimierung
  • Auto-Fixes
  • Hidden Defaults

Technischer Minimal-Stack

  • JSON Schema Validator (AJV o.ä.)
  • SVG / Canvas
  • Static HTML oder lokale App

D — Plugin-Profile (vollständig)

D.1 Plugin: semantic-hints

Status: optional, nicht-normativ

{
  "extensions": {
    "semantic-hints": {
      "prompt_tags": ["wide angle", "cinematic lighting"],
      "style_bias": "photorealistic",
      "llm_safe": true
    }
  }
}
  • Darf ignoriert werden
  • Darf entfernt werden
  • Beeinflusst nie Core-Validität

D.2 Plugin: forensic-profile

{
  "extensions": {
    "forensic-profile": {
      "face_shape": "oval",
      "eye_distance": "wide",
      "nose_type": "roman",
      "special_marks": ["scar_left_eyebrow"]
    }
  }
}
  • Mapping-fähig zu FACES / Polizeisystemen
  • Keine biometrische Identifikation
  • Deskriptiv, nicht eindeutig

D.3 Plugin: cv-observations

{
  "extensions": {
    "cv-observations": {
      "source": "opencv+yolo",
      "objects_detected": ["person", "chair", "table"],
      "confidence": 0.87
    }
  }
}
  • Erlaubt klassische CV-Pipelines
  • Kein Modell vorgeschrieben
  • Rein annotativ

Freeze-Zusammenfassung

  • Core: klein, hart, stabil
  • Inspector: prüfend, nicht interpretierend
  • Plugins: offen, entfernbar, nicht bindend
